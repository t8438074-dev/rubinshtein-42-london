# Rubinshtein Street, 42 — London (V2)

Обновлённая лондонская часть проекта THREE CITIES — ONE ARTIST.

## Что изменено в V2

- Стартовая панорама показывает более прямой, цельный участок улицы; первый экран больше не начинается с центрального угла-корнерстора.
- Маршрут расширен до четырёх отдельных панорамных остановок: The Arrival → The Gallery Row → The Art Windows → The Little Square.
- Все четыре остановки доступны из карты маршрута: строки меню теперь являются активными кнопками.
- Все восемь пользовательских оригиналов подключены как увеличенные рамки с нажатием для просмотра полного изображения.
- Две предоставленные пользователем цитаты встроены как элементы городской среды: настенная табличка и доска книжного магазина.
- На входе добавлен адрес `42 RUBINSHTEIN STREET · LONDON`.
- Увеличены рамки картин, улучшена компоновка мобильного интерфейса.

## Управление

- Мышь / палец: осмотр панорамы.
- Кнопки «НАЗАД» и «ДАЛЬШЕ»: переход между участками.
- Кнопка карты: открыть маршрут; каждая остановка кликабельна.
- Нажатие на картину: открыть оригинал.
- Клавиши ← и →: переход между остановками; ESC: закрыть окно.

## Публикация

1. Распаковать ZIP.
2. Загрузить папку `rubinshtein-42-london-v2` в Netlify Drop или опубликовать из GitHub Pages.
3. Для Netlify не загружать каждую пробную сборку как production deploy: бесплатные deploy previews и branch deploys бесплатны по кредитам; каждый успешный production deploy расходует 15 кредитов.

## Технические примечания

- Это прогулка по четырём 360° панорамным точкам, не свободная 3D-игра с физикой персонажа.
- Панорамный просмотрщик Pannellum 2.5.6 загружается с jsDelivr CDN; для работы нужен интернет.
- Оригинальные работы находятся в `assets/artworks/`.
- Поисковая индексация отключена через `noindex` и `robots.txt`, но это не парольная защита: любой, у кого есть URL, сможет открыть сайт.
- Панорамные окружения созданы ИИ; оригинальные картины загружены отдельно и не должны подменяться ИИ-генерациями.
